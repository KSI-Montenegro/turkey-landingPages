2. Browser configuration uses `/api/config`, served by the included Vercel function, instead of the static ChatGPT config file. Vercel environment variables can therefore control optional tracking.
3. The export removes the original hosting metadata and static config. Canonical, Turkish hreflang, social URL, sitemap and robots configuration use the new deployment origin.
4. Both `/` and `/tr/karadaga-tasinan-aileler` are generated together from the same HTML.
5. CSS, image bytes and visible page content are preserved. No proprietary fonts or runtime credentials were added.
